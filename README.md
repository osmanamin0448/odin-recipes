# Odin recipes
A simple, clean recipe website built as part of **The Odin Project** Foundation curriculum  
<https://www.theodinproject.com/lessons/foundations-recipes>

## Description

Odin Recipes is a static multi-page website that demonstrates foundational HTML skills: semantic markup, proper linking between pages, lists, images, and basic navigation.

It features three delicious recipes with images, descriptions, ingredients, and step-by-step instructions.
